# Contributing

Thanks for your interest in improving this Thai Named Entity Recognition repository.

The project is primarily notebook-based and preserves experiments originally created in 2022. Contributions are especially useful when they improve reproducibility without obscuring the original learning value of the notebooks.

## Good contribution areas

Contributions are welcome for:

- documentation improvements
- fixes for outdated dependency APIs
- clearer preprocessing steps
- reusable helper functions
- consistent evaluation metrics
- notebook cleanup
- modern Hugging Face examples
- lightweight tests or smoke checks
- Thai-language examples and explanations

## Before opening a pull request

1. Keep changes focused and easy to review.
2. Avoid committing datasets, model checkpoints, generated outputs, or credentials.
3. Explain whether your change preserves historical behavior or modernizes it.
4. If changing dependencies, document the tested Python version and package versions.
5. If changing model logic, include the evaluation method and metric definitions.
6. Preserve upstream attribution when adapting external code.

## Suggested pull request format

Please include:

- **What changed**
- **Why it changed**
- **How it was tested**
- **Compatibility notes**
- **Any expected effect on model outputs**

## Data and model licensing

The repository does not grant additional rights to third-party datasets, pretrained models, or libraries. Contributors are responsible for following the relevant upstream licenses and terms.
